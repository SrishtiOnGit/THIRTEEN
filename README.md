# THE THIRTEEN

It's a website made to ship on 3am.. it basically tells you a story and is made in halloween-dark theme. 

## The Purpose : 

For me, the purpose of building this website is to ship at 3am and learn more react concepts.

## What did I learned : 
1. React Components use
2. Typewriter effect in React
3. Use of props
4. How to pass props
5. Use of hooks
6. Use of states

## How to run it locally ? : 
1. git clone https://github.com/SrishtiOnGit/THIRTEEN.git
2. cd client
3. npm install
4. npm run dev

## Live demo : 
Can visit ** https://srishtiongit.github.io/THIRTEEN/** to see it live.
